# ADR 0039: Представление Чата Помощника

- Статус: принято
- Дата: 2026-11-06
- Основание: пользователь запросил polish окна чата, отступы, контейнеры и Markdown.
- Положения о пустом чате сверху и consent заменены [ADR 0040](0040-assistant-direct-entry.md).

## Решение

- Развиваем композицию ADR 0037 в существующем визуальном языке ADR 0003/0010.
  Чат и ввод ограничены читаемой шириной; при наличии черновика на широком
  экране остаются две колонки. Цвета, отступы и радиусы — канонические токены YAM.
- Уточнение после пользовательской приёмки: пустой чат — короткая подсказка
  над вводом, без hero/маскота и растянутой по высоте welcome-области.
  До первого сообщения composer располагается сразу под подсказкой;
  при переписке — у нижнего края. Обычная колонка ограничена 720 logical px.
- Сообщение пользователя — компактный контейнер справа, ответ помощника —
  отдельная спокойная поверхность слева. Текст пользователя остаётся буквальным.
- Ответы, включая промежуточный текст, отображаются как Markdown. Используется
  `flutter_markdown_plus` (Flutter renderer + Dart markdown parser), а не WebView,
  HTML renderer или собственный парсер. Это конкретная dependency для форматирования
  существующего чата; сетевой и domain-контракты не меняются.
- Поддерживаются выделение/копирование текста, заголовки, списки, цитаты, код,
  таблицы и ссылки. Широкие таблицы и fenced code прокручиваются горизонтально.
  Markdown не загружает внешние изображения: фото остаются явными вложениями.
  Ссылки открываются только по нажатию, только абсолютные HTTP/HTTPS URL;
  произвольные схемы и локальные файлы не запускаются.
- Ввод — один контейнер без вложенной рамки/повторной подписи поля:
  `YamTextField.embedded` сохраняет доступную метку и существующие input gestures.
  Дата/приём — content-sized controls в toolbar, а не растянутые form fields;
  на узких окнах и с крупным текстом они переносятся в отдельную строку.
  Send/Stop — иконка с tooltip на всех ширинах. Кнопки AppBar разделены зазором
  8 px и отступом 16 px от края, без отдельных декоративных поверхностей.
  Touch targets ввода и контекстных селекторов остаются ≥44 logical px.
  При малой высоте ввод/ошибки прокручиваются. Пока открыта клавиатура,
  date/meal controls скрыты без потери значений.
- Сессионность диалога, consent, отправка фото/голоса и явное подтверждение
  черновика из ADR 0037 остаются прежними. Новых persisted данных нет.

## Проверка

- Реальный Flutter UI: длинный ответ, заголовки/списки/таблица/код, ввод, ожидание,
  светлая/тёмная темы, узкое окно и увеличенный текст.
- Анализ изменённых Dart-файлов; фокусные проверки поведения ссылок и отсутствия
  неявной загрузки Markdown-изображений.
