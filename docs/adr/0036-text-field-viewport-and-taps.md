# ADR 0036: Граница Текста И Точные Повторные Нажатия

- Статус: принято
- Дата: 2026-11-06
- Область действия: общий `YamTextField`

## Контекст

Длинный однострочный текст обрезается на внутренней границе `contentPadding`,
хотя пользователь ожидает прокрутку через отступ до края поля. Кроме того,
Flutter объединяет быстрые нажатия на расстоянии до 100 logical px в одну
серию: попытка переставить курсор в другое место может выделить слово.

## Решение

- Сохранить существующие токены отступов, цвета и форму поля.
- Для однострочного редактора разрешить рисование за внутренним viewport,
  ограничив его внутренним краем рамки. Обрезка применяется к редактору через
  ScrollBehavior, а не к декорации: текст не перекрывает outline и ошибки.
  Многострочный ввод сохраняет внутреннюю обрезку.
- Для серии нажатий использовать допустимое смещение `computeHitSlop` текущего
  устройства, для мыши — `kDoubleTapTouchSlop`, вместо широкого допуска Flutter.
  Интервал между нажатиями отсчитывается от отпускания предыдущего указателя.
- Нажатие в другом месте начинает новую логическую серию. Намеренные повторные
  нажатия рядом, удержание, выделение мышью и клавиатурные сочетания сохраняются.
- Не заменять Material TextField и не копировать алгоритмы выбора слов/строк/
  абзацев: скорректированную серию передавать публичному платформенному
  `TextSelectionGestureDetectorBuilder` через делегат существующего поля.
  Не добавлять конкурирующий GestureDetector и не отключать выделение.

Это уточнение взаимодействия общих полей в рамках ADR 0003/0010, а не изменение
дизайн-токенов, схемы данных или модели сохранения продукта.
