# ADR 0004: Адаптивная Навигация

- Статус: принято
- Дата: 2026-09-15
- Источники: ADR 0002, ADR 0003 и `agents/PROJECT_BLUEPRINT.md`, разделы 26-27.

## Контекст

YAM имеет три основных раздела и должен одинаково полноценно работать на телефонах, планшетах и desktop. Растягивание нижней мобильной навигации на широкое окно ухудшает использование пространства, а отдельные деревья экранов для каждой платформы усложняют поддержку.

## Решение

- Навигация реализуется через `go_router` и `StatefulShellRoute.indexedStack`, чтобы каждый основной раздел сохранял собственное состояние.
- При ширине меньше 800 dp используется нижний `NavigationBar`.
- Начиная с 800 dp используется боковой `NavigationRail`; начиная с 1200 dp rail показывает постоянные текстовые подписи.
- Содержимое дневника ограничивается шириной 1120 dp и переходит к двухколоночной композиции начиная с 1040 dp доступной ширины контента.
- Breakpoints хранятся централизованно в `lib/app/theme/app_breakpoints.dart`. Решение зависит от доступных constraints, а не от типа платформы или ориентации.

## Последствия

- Телефон в landscape и узкое desktop-окно получают layout, соответствующий фактическому пространству.
- Feature screens не знают, какой navigation component их окружает.
- Breakpoints можно скорректировать после проверки на реальных устройствах без изменения маршрутов и feature-кода.
