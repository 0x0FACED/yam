# ADR 0048: Консистентность UI И Восстановление После Ошибок

- Статус: принято
- Дата: 2026-11-08
- Основание: пользователь одобрил исправление 11 замечаний UI Consistency & Visual Quality Audit.

## Решение

Сохраняются визуальное направление ADR 0003, приоритеты ADR 0010, семантические
токены и floating-композиция ADR 0046/0047. Глобального редизайна нет.

- Ошибки чтения Дневника и Статистики имеют локализованное экранное состояние
  и явный повтор подписки. Отсутствие данных не подменяет ошибку чтения;
  устаревшие события прежней даты/периода не меняют текущий экран.
- Меню темы, приёма пищи и единицы порции сохраняют естественную высоту,
  но прокручиваются при недостатке места. Ошибка запуска с повтором также
  доступна в низком viewport и с увеличенным текстом.
- Loading-индикатор основной кнопки использует контрастный цвет её текущей
  поверхности. Loading по-прежнему не допускает повторного нажатия.
- Короткие chips сохраняют интерактивную область минимум 44×44 logical px;
  видимая компактная форма не обязана занимать весь target.
- Недоступность полей помощника выражается единообразно: внешний вид,
  pointer-ввод, клавиатурный focus и accessibility. Открытое меню закрывается
  при отключении; уже выполняющийся запрос и его контекст не меняются.
- Заголовок create/edit формы ограничен доступной шириной и переносится.
  Подробный редактор записи показывает полное название продукта, как quick-add;
  краткие строки каталога и Дневника не расширяются.
- Быстрые порции показывают полную подпись без многоточия. Горизонтальная
  прокрутка сохраняется; выбор не должен сокращать подпись из-за check-маркера.
- Календарь Статистики отличает записанный день без цели от отсутствия записей
  нейтральной отметкой, согласованной по смыслу с Дневником (ADR 0029).
- Действия app-owned диалогов используют общие YAM-кнопки; системные диалоги
  не переоформляются.

Данные, расчёты, SQLite schema, форматы обмена, зависимости и палитра не меняются.

## Проверка

Фокусные regression-сценарии ошибок/повтора и disabled/focus; native smoke
с изолированными данными: RU/EN, Light/Dark, 320/360 logical px, низкое окно,
текст ×2, длинные названия/порции и прокрутка к последнему варианту. Форматирование
изменённого Dart и `flutter analyze`. Синтетические insets не заменяют приёмку
системной клавиатуры на физическом Android/iOS.
