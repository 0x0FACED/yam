# ADR 0053: Отображение Версии Приложения Без Номера Сборки

- Статус: принято
- Дата: 2026-11-13
- Область действия: пользовательское отображение версий приложения

## Контекст

Номер сборки необходим пакетам и механизму обновлений, но суффикс `+BUILD`
загромождает отображаемую пользователю версию.

## Решение

- В настройках, на экране «О приложении» и в состояниях обновления показывается
  только версия `MAJOR.MINOR.PATCH`, без номера сборки.
- Версия и номер сборки по-прежнему считываются из metadata пакета. Формат
  `pubspec.yaml`, Android versionCode, сравнение и проверка обновлений, теги
  и имена артефактов не меняются.
- Это явно изменяет требование ADR 0025 показывать в Settings и About оба поля;
  остальные контракты ADR 0025 и ADR 0035 сохраняются.
