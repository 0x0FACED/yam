# ADR 0046: Настоящие Floating-Действия Над Viewport

- Статус: принято
- Дата: 2026-11-07
- Основание: пользователь отклонил визуальную приёмку ADR 0045 и уточнил ожидаемый эффект на скриншотах.

## Решение

- Этот ADR заменяет реализацию floating как отдельного элемента в нижней строке
  `Column` из ADR 0045. Отступы у прикреплённого футера не являются floating.
- Основное нижнее действие позиционируется поверх полного viewport прокрутки.
  Вокруг кнопки нет заполненной фоновой панели, рамки или непрозрачной полосы.
  Существующие цвет, радиус и текст самой кнопки сохраняются; добавляется мягкая
  тень из общих elevation-токенов.
- Контент прокручивается под действием и виден через промежутки вокруг него.
  Конечный scroll padding равен измеренной высоте overlay плюс нижний отступ
  и зазор; последний элемент можно поднять выше кнопки при любом масштабе текста.
- Внешний отступ overlay — 16 logical px внутри safe area; ещё 12 px прозрачного
  пространства вокруг кнопки оставлено для тени. Итоговый зазор кнопки — 28 px.
  Клавиатурные insets учитываются одним владельцем: Scaffold для экранов,
  существующий inset wrapper для модальных листов. Overlay не рисует фон safe area.
- Одинаковый паттерн используется в create/edit продукта, quick add, edit diary,
  весе, целях/онбординге, прокси, подтверждении черновика и action sheets обмена.
  Сам модальный лист сохраняет свою поверхность: удаляется только футер вокруг
  действия. Обычные кнопки внутри содержимого и основная навигация не меняются.
- В чате поле ввода, ошибки и действия черновика образуют overlay над полной
  областью переписки. У ошибки/ввода остаётся собственная семантическая поверхность
  и мягкая тень, но нет общей непрозрачной подложки, обрезающей сообщения сверху.
- На маленькой высоте и с крупным текстом overlay ограничен viewport и прокручивается;
  важные действия и последние поля остаются достижимы, без overflow.

## Проверка

- Визуально: под кнопкой и в боковых/нижнем зазорах виден прокручиваемый контент,
  нет полосы или контейнера вокруг кнопки; тень принадлежит самой кнопке.
- Native сценарии light/dark, compact/wide, увеличенный текст, scroll-to-end,
  синтетические keyboard/safe-area insets и выполнение действий.
- Форматирование и анализ Dart; существующие поведенческие проверки затронутых
  экранов. Реальная системная клавиатура Android/iOS требует мобильного устройства.
