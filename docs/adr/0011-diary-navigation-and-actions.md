# ADR 0011: Навигация По Датам И Действия Дневника

- Статус: принято
- Дата: 2026-09-23
- Область действия: presentation UI Дневника

## Контекст

При выборе другой даты кнопка возврата к сегодня добавляла строку под календарём
и сдвигала весь дневник. Сегодняшний день переставал выделяться в недельной
строке. Маленькие видимые кнопки добавления в приёмы пищи терялись на фоне
заголовков, а возврат к общему добавлению требовал входа через конкретный
приём. Глобальное отключение overscroll мешало привычному отклику Android.

## Решение

- Недельная строка отмечает сегодняшний локальный календарный день точкой
  независимо от выбранной даты; выбранный день сохраняет отдельную заливку.
- Возврат к сегодня доступен в закреплённом заголовке при просмотре других дат.
  Он не добавляет высоту к календарю или содержимому дневника.
- Фиолетовая плавающая кнопка общего добавления возвращается в Дневник и
  открывает поиск с явным выбором приёма пищи. Контекстные кнопки в каждом
  приёме сохраняют его предварительный выбор.
- Видимые контекстные кнопки становятся крупнее, при этом их область нажатия
  остаётся не меньше 44 dp. Заголовки приёмов уплотняются, число калорий и
  единица измерения получают разную типографическую значимость.
- Для прокрутки Дневника на Android используется штатный Material overscroll
  со stretch-откликом. Поведение других экранов этим решением не меняется.

Этот ADR **заменяет** пункт ADR 0010 об удалении глобального Diary FAB и
соответствующее ограничение экранного HTML-эталона. Остальные решения ADR 0010
сохраняются: композиция экрана следует эталону там, где не оговорено выше,
а доступная область нажатия компактных элементов остаётся не меньше 44 dp.

## Последствия

Общая и контекстные кнопки ведут в один и тот же существующий сценарий поиска.
Нижняя часть списка должна оставаться доступной за плавающей кнопкой. Поведение
при смене даты и широкая/узкая компоновки покрываются тестами.
