# ADR 0035: Название GitHub Release Без Номера Сборки

- Статус: принято
- Дата: 2026-11-06
- Область действия: публичное название GitHub Release

## Контекст

Пользователь хочет видеть `YAM 0.4.0`, а не `YAM 0.4.0+9` в заголовке релиза.
Номер сборки нужен пакетам и механизму обновлений, но не этому заголовку.

## Решение

- Release workflow берёт заголовок `YAM MAJOR.MINOR.PATCH` из проверенного
  выхода `version` существующего `tool/release_metadata.dart`.
- Теги, имена скачиваемых артефактов, package metadata, Android versionCode
  и проверка обновлений не меняются. В именах артефактов сохраняется `+BUILD`.
- Изменение применяется к будущим публикациям; ранее опубликованные релизы
  автоматически не переименовываются.

Это уточняет раздел «Релиз» ADR 0025 о CI и версиях; контракт версионирования
ADR 0005 и заметок ADR 0031 остаётся прежним.
