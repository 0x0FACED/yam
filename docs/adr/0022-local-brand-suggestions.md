# ADR 0022: Локальные Подсказки Брендов

- Статус: принято
- Дата: 2026-09-28
- Область действия: поле бренда в форме создания продукта

## Контекст

Бренды уже хранятся у созданных пользователем продуктов и выбранных продуктов
Open Food Facts. Повторный ручной ввод замедляет создание продукта.

## Решение

- При открытии формы читать бренды неудалённых `UserFoods` и `RemoteFoods` из
  локальной SQLite через репозиторий. Не использовать сеть или отдельную таблицу.
- Убирать пробелы по краям, пустые значения и дубли без учёта регистра; порядок
  стабилен и не зависит от порядка чтения таблиц.
- Во время ввода предлагать не более пяти совпадений по префиксу. Выбор
  доступен касанием, мышью и клавиатурой. Поле остаётся свободным: выбор
  предложения не обязателен, произвольный бренд сохраняется как прежде.
- Новые бренды становятся доступны при следующем открытии формы после
  сохранения продукта. Удалённые продукты не участвуют в подсказках.

## Последствия

Схема, миграции и формат сохранения продукта не меняются. Это уточняет UX формы
из ADR 0016; правила кэширования OFF из ADR 0021 сохраняются.
