# ADR 0040: Прямое Открытие Чата Помощника

- Статус: принято
- Дата: 2026-11-06
- Основание: пользователь запросил ввод всегда снизу и открытие без повторного объяснения.

## Решение

- Экран помощника сразу открывает чат. Промежуточный экран с кнопкой
  «Понятно, открыть помощника» и инструкция в пустом диалоге удалены.
  Не вводим persisted-флаг согласия: он не нужен для выбранного поведения.
- Privacy и уведомление о сессионности переписки доступны в настройках
  подключения, где пользователь настраивает провайдера. До явной отправки
  текст/фото не уходят модели; подтверждение записи черновика остаётся обязательным.
- Composer всегда закреплён у нижней границы доступной области: при пустой
  переписке, после ответа и над клавиатурой. Повторной инструкции в пустом чате нет.
  Compact date/meal controls и touch targets ADR 0039 сохраняются.
  При открытой клавиатуре также скрывается строка модели/usage: в landscape
  высота уходит вводу, а не служебной информации. Бюджет ввода/ошибок считается
  после header, по фактически оставшемуся месту.
- Этот ADR заменяет в ADR 0039 расположение пустого composer сверху и сохранение
  промежуточного consent-экрана. Остальные положения ADR 0037/0039 не меняются:
  session-only диалог, предупреждение о закрытии непустой сессии, local-first,
  credentials, Markdown и ручное подтверждение записи.

## Проверка

- Открытие, закрытие пустого чата и повторный вход без промежуточной кнопки.
- Узкая portrait/landscape-компоновка, увеличенный текст, keyboard inset и safe area:
  поле/Send остаются снизу, видимы и доступны; ввод и ответ не меняют якорь composer.
- Сведения privacy/session доступны на экране подключения; данные и credentials
  пользовательской установки при проверке не изменяются.
